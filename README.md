# Kiri

**Kiri** es una plataforma digital orientada a la promoción del bienestar emocional, la educación en salud mental y la detección temprana de señales de alerta.

Su propósito no es realizar diagnósticos psicológicos, sino acompañar a las personas en el desarrollo del autoconocimiento emocional, la comprensión de sus emociones y conductas, y la identificación de patrones que puedan afectar su bienestar.

La plataforma integra herramientas de **autorregistro emocional, psicoeducación, cuestionarios orientativos, técnicas complementarias, seguimiento del progreso, gamificación, comunidad y acompañamiento digital**.

> **Importante:** Kiri no sustituye la evaluación, diagnóstico, tratamiento ni criterio clínico de un profesional de la salud mental.

---

# Objetivo del proyecto

Kiri busca convertirse en una herramienta preventiva, educativa y de acompañamiento que contribuya a:

- Fortalecer el autoconocimiento emocional.
- Promover hábitos saludables.
- Facilitar el acceso a recursos de psicoeducación.
- Identificar patrones emocionales y conductuales.
- Brindar herramientas de autocuidado.
- Facilitar la detección temprana de posibles señales de alerta.
- Reducir el estigma asociado a la búsqueda de apoyo psicológico.
- Favorecer el acceso oportuno a profesionales de la salud mental cuando sea necesario.

---

## Entrevista inicial

Al comenzar su experiencia en Kiri, el usuario realiza una **entrevista inicial** compuesta por preguntas orientativas.

La información recopilada permite obtener una aproximación inicial al estado emocional del usuario.

Una vez finalizada la entrevista, la plataforma analiza las respuestas proporcionadas y presenta un resumen visual que sirve como base para la personalización de la experiencia dentro de Kiri.

La entrevista inicial no constituye una evaluación diagnóstica.

El objetivo del plan es facilitar al usuario el acceso a contenidos y actividades relacionadas con sus necesidades de bienestar.

# Diario y autorregistro emocional

El módulo **Diario** permite al usuario registrar experiencias relacionadas con su estado emocional y reflexionar sobre ellas.

Actualmente contempla diferentes modalidades de autorregistro.

## Diario emocional

Permite registrar:

- Emoción experimentada.
- Situación o motivo relacionado.
- Reacción ante la situación.
- Una idea útil obtenida de la experiencia.

## Observando mis pensamientos

Orientado a facilitar la observación de:

- Situaciones.
- Pensamientos.
- Sentimientos.
- Reacciones.

## Autorregistro ABCDE

Permite reflexionar de manera estructurada sobre una situación, las creencias asociadas y posibles nuevas formas de responder.

El módulo también permite:

- Consultar entradas recientes.
- Acceder al historial de registros.
- Visualizar el detalle de una entrada.
- Editar registros existentes.
- Eliminar registros.
- Identificar emociones asociadas.
- Dar seguimiento al número de entradas realizadas.

Estos registros buscan favorecer la identificación de patrones emocionales y conductuales a lo largo del tiempo.

Estos instrumentos permiten explorar aspectos relacionados con:

- Bienestar emocional.
- Autoestima.
- Ansiedad.

# Roles del sistema

Kiri utiliza un modelo de control de acceso basado en roles (**RBAC — Role-Based Access Control**).

| Rol                             | Alcance                                                                                           |
| ------------------------------- | ------------------------------------------------------------------------------------------------- |
| **Superadministrador**          | Administra la plataforma a nivel global y dispone del mayor nivel de privilegios.                 |
| **Administrador Institucional** | Gestiona las funcionalidades administrativas correspondientes a su institución.                   |
| **Psicólogo Institucional**     | Participa en funciones de seguimiento y acompañamiento autorizadas dentro de la institución.      |
| **Docente**                     | Accede a funcionalidades institucionales y preventivas correspondientes a los grupos autorizados. |
| **Estudiante / Usuario**        | Utiliza las herramientas de bienestar emocional y consulta su información personal.               |

Las capacidades específicas de cada rol continuarán ampliándose conforme avance el desarrollo de la plataforma.

# Arquitectura general

La aplicación sigue una organización modular para separar responsabilidades entre interfaces, componentes, lógica de negocio y acceso a datos.

Una estructura simplificada del proyecto es:

```text
Kiri/
├── app/
│   ├── (auth)/
│   ├── (tabs)/
│   ├── (entrevista)/
│   ├── (tecnica)/
│   └── (superadmin)/
│
├── assets/
├── components/
├── constants/
├── contexts/
├── hooks/
├── services/
└── types/
```

### `app/`

Contiene las rutas y pantallas gestionadas mediante **Expo Router**.

### `components/`

Contiene componentes visuales reutilizables.

### `services/`

Contiene la lógica relacionada con consultas, autenticación y comunicación con Supabase.

### `contexts/`

Contiene proveedores globales de estado, como el sistema de temas.

### `hooks/`

Contiene hooks reutilizables utilizados por la aplicación.

### `types/`

Contiene interfaces y tipos utilizados por TypeScript.

### `constants/`

Contiene configuraciones y valores compartidos, incluyendo el sistema de colores de Kiri.

# Instalación

## 1. Clonar el repositorio

```bash
git clone https://github.com/vanessamoralesm-ing/Kiri.git
```

## 2. Entrar al proyecto

```bash
cd Kiri
```

> Si la carpeta local del proyecto posee otro nombre, utiliza ese nombre en el comando `cd`.

## 3. Instalar dependencias

```bash
npm install
```

---

# Variables de entorno

Crear en la raíz del proyecto el archivo:

```text
.env.local
```

Agregar las variables correspondientes a Supabase:

```env
EXPO_PUBLIC_SUPABASE_URL=SUPABASE_URL
EXPO_PUBLIC_SUPABASE_KEY=SUPABASE_KEY
```

Reemplaza los valores de ejemplo por las credenciales correspondientes al proyecto.

> Las credenciales sensibles que no deban exponerse públicamente no deben almacenarse directamente en el repositorio.
